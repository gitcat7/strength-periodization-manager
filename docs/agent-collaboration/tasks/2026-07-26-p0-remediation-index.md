# P0 整改任务总览

来源：`需求` 任务于 2026-07-26 完成的产品与工程审计。

## 目标

修复会破坏「生成计划 → 记录训练 → 自动调整」闭环、可能误导新手加重，或导致训练数据半完成的 P0 缺陷。所有任务均不得读取 `.env*`、连接生产 Supabase、推送或部署。

## 委派顺序

1. `2026-07-26-p0-coach-target-attainment.md`：先阻止未达标训练被建议加重。
2. `2026-07-26-p0-recommendation-periodization.md`：保留 A/B 与减量周的周期差异。
3. `2026-07-26-p0-workout-completion-transaction.md`：收口 Web 与 Agent 的完成训练规则。
4. `2026-07-26-p0-profile-driven-program.md`：让画像真实影响训练处方。

第 1 项必须先完成。第 2、3 项都涉及建议语义，建议串行执行；第 4 项在第 1 项完成后可独立进行，但需在合并前与第 2、3 项复核接口兼容性。

## 共通交付规则

- 每项从 `main` 的最新已验证提交创建独立 worktree 与 `claude/*` 分支。
- 先运行指定的红灯测试，再做最小实现；不得通过放宽断言或跳过测试获得通过。
- 提交前运行 `git diff --check`、任务内命令和 `pnpm release:check`。
- 不推送、不部署、不执行生产迁移。涉及数据库的任务只新增迁移与本地契约测试。
- 若发现需要修改任务允许范围外文件，停止并说明原因，等待架构师扩大范围。

## 合并后总验收

```powershell
pnpm test
pnpm typecheck
pnpm release:check
git diff --check
```

另需以测试用户完成一次完整闭环：生成计划、低于目标完成训练、确认不加重；达标完成训练、确认建议仅影响正确的周期上下文；通过 Web 与 Agent 各完成一次训练，确认数据一致。
