# 历史 Tab 与单次训练入口设计

## 目标

让没有周期计划的用户能从底部导航直接进入训练历史，快速找到已保存的单次训练记录。

## 导航方案

底部导航维持五个入口：今日、计划、进展、历史、设置。

“历史”替换当前的“PR”位置，使用历史图标并链接至 `/history`。保留 `/pr` 路由与既有首页、进展页入口，不删除 PR 目标功能或数据。

## 用户流程

无计划用户从首页进入“记录今日训练”，完成单次训练后，记录继续保存到现有的历史与进展数据源。用户随后可通过底部“历史”Tab查看所有记录，或通过完成页的直达链接查看本次记录。

有周期计划用户的训练历史行为不变；底部“历史”Tab同样展示计划内训练与单次训练。

## 实现范围

- 更新 `src/components/navigation/bottom-nav.tsx` 的导航项与图标。
- 更新导航相关测试，覆盖“历史”Tab 存在、`/history` 激活态和 PR 不再位于底部导航。
- 不修改单次训练保存逻辑、历史查询逻辑、数据库结构或 PR 页面。

## 验收

- 所有页面底部都显示“历史”Tab（登录/认证页除外）。
- 在 `/history` 时“历史”Tab 显示为激活状态。
- 单次训练完成后仍可从历史查看该记录。
- 现有 PR 路由可正常访问。
