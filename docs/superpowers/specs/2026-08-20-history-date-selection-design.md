# 历史页按日期查看设计

## 目标

历史页进入时只展示月历和页面级统计，不默认展开任何一天；用户明确点击日期后，才展示该日期的计划或已完成训练内容。

## 交互

- `selectedDate` 初始为 `null`。
- 月份数据加载完成后不得自动选择今天或其他日期。
- 点击有记录或有计划的日期后，将该日期设为选中并展示日期摘要与现有详情。
- 切换月份时清空选中日期，避免把前一个月的详情留在新月份下。
- 通过 `/history?workout=<id>` 进入时保留现有聚焦行为：仅当记录属于当前已加载月份且属于当前用户时选中对应日期。
- 现有历史记录编辑、保存、Coach 展示、RLS 查询和缓存语义不变。

## 验收

1. 默认 DOM 不包含“当天训练摘要”或训练详情卡。
2. 点击日期后只显示该日期内容。
3. 切换月份后详情消失，仍可点击新月份日期查看。
4. 通过 workout 参数进入的记录仍能选中日期并聚焦详情。
5. 不新增 SQL/migration/RPC，不改变训练算法。
