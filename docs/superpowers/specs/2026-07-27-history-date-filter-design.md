# 历史训练按日期查看设计

## 目标

让用户可以在历史页选择一个日期，只查看当天的完成训练、动作组记录、复盘和 Coach 建议。

## 交互

- 历史页默认展示全部已完成训练，而非最近 12 次。
- 顶部提供原生日期选择器与“全部历史”按钮。
- 选择日期后仅渲染 `scheduled_date` 与所选日期相同的训练卡片；同日多次训练全部显示。
- 日期没有完成训练时，显示明确的空状态，并可一键回到全部历史。
- 从其他页面携带 `?workout=<id>` 跳转时，保留现有聚焦和滚动行为；该聚焦不受日期筛选影响。

## 数据与性能

继续使用现有按用户、已完成状态、日期倒序的 Supabase 查询，移除 `limit(12)`，让存量记录可被日期筛选。筛选在浏览器内对已载入记录执行，不新增数据库结构或写操作。

## 验证

- 域测试验证相同日期的多条记录均被保留、空日期得到空集合。
- 组件测试验证日期控件、全部历史按钮和空状态。
- 完整发布检查与生产路由冒烟检查。
