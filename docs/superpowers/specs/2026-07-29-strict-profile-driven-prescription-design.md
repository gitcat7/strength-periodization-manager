# 严格画像驱动处方设计

## 目标

让计划生成器基于用户的真实训练画像生成可执行的处方，而不是用同一套基础模板叠加少量百分比。重点修复增肌计划中辅助动作被错误降到 `2.5kg` 的问题，并让训练经验、可训练频率和恢复条件对训练量与强度产生明确、可验证的影响。

## 已确认的输入口径

- 主项输入是**最近稳定完成的工作组**：重量与次数；不是 1RM。
- 如需支持 1RM，后续新增明确的输入模式，不能猜测或混用。
- 用户的具体示例数据不构成固定处方阈值；算法必须适用于不同能力水平。

## 已发现的问题

当前流程先将工作组估算为 1RM，再取 90% 训练最大值，又反推为 5RM，最后把同一强度系数用于主项和辅助动作。这个链路对主项过度保守，且会把由主项推导的辅助动作再次按主项百分比压低；例如侧平举可能落到 `2.5kg`。

训练经验目前只统一调整少量组数和强度，无法影响计划的周训练量、频率适配或进阶速度。

## 设计

### 1. 分层负荷锚点

生成器为每个动作标记处方层级，而不是只依赖一个 `intensity`：

- `primary`：用户直接填写的四个主项。以工作组估算的 e1RM 为能力锚点，按目标次数区间反推目标重量；仅在安全范围内使用训练最大值。
- `secondary`：与主项相近的复合动作。使用对应主项能力锚点与动作专属比例，避免把 5 次工作重量直接当成所有次数范围的基准。
- `accessory`：孤立或器械辅助动作。使用动作专属起始工作重量（或历史完成重量）和独立的次数区间；不得套用主项强度系数。重量必须保留动作自身的最小增量。
- 自重动作继续为 `0kg`，只处方组数、次数及进阶提示。

### 2. 目标、经验和频率的严格规则

计划生成时同时使用以下参数，并在纯领域测试中逐项证明会影响结果：

| 参数 | 作用 |
| --- | --- |
| 主要目标 | 决定主项/次主项/辅助动作的次数区间、每肌群周有效组范围和减量策略。 |
| 训练经验 | 决定每肌群起始有效组、主项数量上限、强度上限和周进阶幅度。初级优先技术与一致性；中级可承受更高容量和更细分的 A/B。 |
| 主项工作组重量与次数 | 估算能力锚点，决定主项及关联次主项的重量，不作为辅助动作百分比的二次来源。 |
| 每周训练天数与可训练日 | 决定模板选择和每周暴露频率，避免把六日 A/B 模板硬压进三天。 |
| 计划周数 | 决定渐进与减量安排；四周仍保留减量周，较长周期在每个四周小周期重复。 |
| 伤病/禁忌说明 | 保留现有人工提示与替换边界，不做医疗自动判断。 |
| 当前体重、目标变化率、近 14 天变化 | 在减脂/塑形情境下判断能量可用性，收紧容量，不盲目增加训练量。 |
| 饮食执行度、蛋白完成度、恢复状态 | 控制总组数、减量周和进阶；不得用于虚构生理诊断。 |

### 3. 增肌处方

- 主项以 `5–10` 次为主，次主项 `6–12` 次，辅助动作 `8–20` 次；每个动作的实际次数由模板层级而非全局“+3 次”决定。
- 各肌群按经验等级获得不同的起始有效组预算；训练天数不足时优先保证主项与关键肌群频率，不堆叠同日无意义动作。
- 中级增肌使用更高容量与更明确的 A/B 区分；初级不因选择增肌而直接获得中级容量。
- 第四周以较低总量保留技术练习；若恢复、饮食或体重变化提示风险，则更早/更明显地下调。

### 4. 可解释性

计划页在生成预览附近显示“本计划参考的参数”：目标、训练经验、每周训练天数、主项工作组、恢复状态；体重/饮食信息仅在被用于容量保护时显示。该说明只解释已使用的用户输入，不显示医学或营养诊断。

## 不在本次范围

- 不新增 1RM 输入模式。
- 不创建医疗建议、疼痛诊断或营养处方。
- 不改动历史训练数据和已有计划；新规则仅用于新建/重新生成计划。

## 验收标准

1. 增肌、中级与初级用户在相同主项能力和频率下，得到不同且合理的组数/次数/重量处方。
2. 更高的主项工作组能力会提高对应主项和次主项重量，不会把辅助动作压到不合理低值。
3. 侧平举、面拉、弯举等辅助动作不使用主项强度百分比；动作重量按自身锚点和最小增量输出。
4. 每周训练天数会影响模板暴露频率和容量分配。
5. 恢复/能量可用性风险只会降低或维持容量，不会增加训练负荷。
6. 计划页面能准确列出实际参与生成的关键参数。
7. 所有既有领域、组件、构建和冒烟测试通过。
